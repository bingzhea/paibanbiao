# 工作排班表

一个面向小规模团队的离线休假排班工具。项目由单个 HTML 文件组成，无需安装依赖或部署服务器，使用浏览器即可维护人员、节假日和月度休假计划。

## 功能

- 人员新增、改名、启用和停用
- 节假日名称及日期范围维护
- 按人员、月份编辑休假计划
- 编辑内容确认后保存，退出编辑可放弃本次修改
- 显示计划休假天数、最后确认日期及今日休假状态
- 按月统计每日休假人数
- 浏览器本地自动保存
- JSON 数据备份与恢复

## 使用方法

1. 下载项目中的 [`worklog.html`](./worklog.html)。
2. 使用最新版 Microsoft Edge 或 Google Chrome 打开该文件。
3. 先维护人员和节假日，再在“休假排班”中选择人员与月份。
4. 点击“开始编辑”调整日期，完成后点击“确认本月排班”。
5. 定期使用“导出备份”保存 JSON 备份文件。

## 数据说明

排班数据保存在当前浏览器的本地存储中，不会上传到服务器。以下操作可能导致本地数据不可用：

- 清理浏览器网站数据
- 更换浏览器或电脑
- 移动或重命名 HTML 文件后，浏览器将其识别为新的本地页面

建议在修改文件位置、清理浏览器数据或更换设备前先导出 JSON 备份，再通过“恢复备份”导入。
